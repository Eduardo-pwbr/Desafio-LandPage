# 🚀 Desafio Front-end Concluído com Sucesso

Este desafio de Front-end foi desenvolvido utilizando apenas **HTML, CSS e JavaScript**, sem integração com API. Mesmo sendo um projeto simples, ele foi uma ótima oportunidade para reforçar conceitos fundamentais do desenvolvimento web.

## 🧠 O que foi trabalhado

✔ Estruturação semântica com **HTML**  
✔ Estilização responsiva e organizada com **CSS**  
✔ Interatividade com **JavaScript**  
✔ Boas práticas de código e organização de arquivos  

Cada detalhe do layout, comportamento dos elementos e experiência do usuário foi pensado com atenção. Finalizar esse desafio mostrou como, com as tecnologias básicas, já é possível construir interfaces funcionais, bem estruturadas e agradáveis de usar.

---

## ▶️ Como executar o projeto

Você pode rodar o projeto de duas formas:

### 🔹 Opção 1 — Abrir direto no navegador  
Basta baixar os arquivos e abrir o arquivo:

```
index.html
```

em qualquer navegador.

### 🔹 Opção 2 — Usando um servidor local (opcional)

Se preferir, você pode usar a extensão **Live Server** no VS Code:

1. Abra o projeto no VS Code  
2. Clique com o botão direito no arquivo `index.html`  
3. Selecione **"Open with Live Server"**

Pronto — o projeto abrirá no navegador.
